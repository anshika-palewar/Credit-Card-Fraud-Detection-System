# 💳 Credit Card Fraud Detection System

## 📌 Project Overview
Credit Card Fraud Detection is a Machine Learning-based project designed to identify fraudulent credit card transactions and distinguish them from legitimate transactions.

The project uses classification algorithms to detect suspicious transaction patterns and improve financial transaction security.

## 🎯 Problem Statement
With the increasing use of online payments, credit card fraud has become a major concern. Traditional rule-based systems often fail to identify new fraud patterns.

This project aims to develop an automated system that detects fraudulent transactions while minimizing false positives and false negatives.

## 🛠️ Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn

- Seaborn

## 🤖 Machine Learning Algorithms
The project explores the following classification algorithms:

- Logistic Regression
- Random Forest
- XGBoost
- Support Vector Machine (SVM)

## 📊 Dataset
- Source: Kaggle
- Total Transactions: 284,807
- Fraudulent Transactions: 492
- The dataset contains anonymized credit card transaction details.

## ⚙️ Methodology
1. Data Collection
2. Data Preprocessing
3. Handling Class Imbalance using SMOTE
4. Feature Scaling and Data Cleaning
5. Model Training
6. Model Evaluation
7. Performance Comparison

## 📈 Results

The following performance results are reported in the project report:

| Algorithm | Accuracy | F1-Score |
|---|---:|---:|
| Logistic Regression | 97.8% | 87.3% |
| Random Forest | 99.2% | 95.1% |
| XGBoost | 99.4% | 96.6% |
| SVM | 98.1% | 90.0% |

XGBoost achieved the highest reported performance, followed by Random Forest.
